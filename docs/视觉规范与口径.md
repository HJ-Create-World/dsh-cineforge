# CineForge 视觉规范与口径（0.3.2）

本文件是 QA 判例「conscious_violations」的口径依据，只记录**有意识偏离**与**可核验阈值**，
不是设计宣传。判例全文见 `docs/QA-一期返工终检报告.md`。

## Q11 · 9:16 字高口径冲突

- 判例原文：「辅助文字 >= 5.2% 帧高」。在 1920 高的 9:16 画布上等于 `1920 × 0.052 = 99.84 ≈ 100px`。
- 实际采用：`--small-px = max(36, round(w × 0.034))`，9:16 / 1080 宽 → `37px`。
- 冲突原因：100px 的辅助文字会与抖音竖屏字幕安全区（底部约 15%~20%）及标题层级竞争，
  同一行 `mini-card` 的 label/meta 会被挤出画面；这是**有意识偏离**，不是漏改。
- 补偿措施：`.mini-card .meta` 由 `calc(var(--small-px) * 0.80)`（29.6px）提到 `var(--small-px)`（37px），
  并取消 `overflow-wrap: anywhere`（改 `white-space: nowrap` + 省略号）。这样同时满足 >=32px 的绝对底线。
- 口径：本项目以「>= 32px 绝对像素」为 9:16 辅助文字底线，5.2% 帧高判例保留但不适用竖屏字卡模板。
  横屏 1920×1080 下若按 5.2% 需 56px，同样高于 32px；后续单独出横屏版式时再评估。

## Q7 · styleframe_refs = []

- 一期为「模板可行性验证片」，无真实产品页面截图，不是复刻场景。
- 上游 video-shotcraft 的核心理念是「真实截图 + 从产品生长出的视觉语言」；本片深墨底 + 琥珀字标
  是占位风格，不代表任何真实产品的视觉识别。承接真实项目时必须先补 styleframe。

## C1 · voiceover = [] / 无硬字幕

- 纯字卡段落没有解说轨与硬字幕轨；一期标注 `NOT FOR PUBLISH`，`publish_allowed: false`。
- 字幕不是「画面文字」：画面内 title/sub 属于构图元素，不能替代可关闭的硬字幕。

## Q5 / Q8 · 整镜重做的验收口径

- Q5 开场：单主体（字标 + 光环 + 聚光），无 eyebrow / foot / 进度条；动作弧必须可拆成
  聚光 → 推近 → 悬浮 → 描边光 → 归位五段，且第 0 帧非空。
- Q8 收尾：四个已展示功能代表元素从四方飞入 + 舞台光 + 粒子 + 字标落定；
  18.5s 与 19.75s 两帧**不得逐字节相同**（旧版 f555=f593 是判定失败的直接证据）。

## 安全区（9:16 / 1080×1920）

- 由 `buildCss()` 换算为 px（CSS 百分比 padding 只按宽度解析，故一律不用百分比）。
- `--pt: 346px` / `--pb: 691px` / `--pl: 140px` / `--pr: 324px`。
- 判例文字安全区：left >= 120 / right <= 780 / top >= 288 / bottom <= 1248。
- 0.3.2 用 `.shot__bg::before`（页眉细线）与 `::after`（底部渐隐信息带）填掉 pb 留白，
  但**不把文字放进该区域**，只增加出版级密度，不改安全区。
