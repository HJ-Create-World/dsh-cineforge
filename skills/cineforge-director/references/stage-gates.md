# 阶段门与放行条件

每个阶段有明确的**进入条件**与**产出验收**。不满足产出验收不得推进——这是防返工的核心机制。

| 阶段 | 进入条件 | 产出验收（必须全部满足） |
|---|---|---|
| 0 Idea 扩写 | 用户给了 idea | 简报含受众/目标/平台/画幅/时长/语言/模式；画幅与平台一致 |
| 1 文案 | 简报已定 | 钩子可在 3s 内成立；CTA 明确；平台化标题与标签齐全；字卡与 outro 文案不重复 |
| 2 素材理解 | 文案已定 | 产品简报 + 需求决策表；敏感数据口径已冻结；素材风险已列 |
| 3 视觉方向 | 阶段 2 完成 | 设计 spec 含色板/字体/光感/动效 tokens；styleframe ≥2 张静态帧已截图验证；未写任何渲染代码 |
| 4 动效映射 | 阶段 3 完成 | 每个必须展示的功能都有首选卡 + 备选卡；手法不重复；卡名与 style-key 已校验 |
| 5 分镜 | 阶段 4 完成 | 分镜表 11 列齐全；帧预算含 hold/rest；能量曲线符合 arc；每镜 2 个验收帧号；**用户已确认** |
| 6 素材采集 | **阶段 5 已放行** | 全页 2x 截图 + 元素切片 + layout.json；可重跑的采集脚本；数据已脱敏 |
| 7 逐镜实现 | 阶段 6 完成 | 每镜静帧已肉眼验收；整片可渲；props + schema 已暴露；无 Date.now/Math.random |
| 8 声音 | 阶段 7 完成 | BGM 网格验收通过（若卡点）；SFX 从 SHOTS 派生；带/无 BGM 两版可渲 |
| 9 终检 | 阶段 8 完成 | 独立 subagent 报告逐条 `编号 ✓/✗(镜头·帧号)`；无未解释的 ✗ |
| 10 发布 | 阶段 9 完成 | dry-run 通过；用户已确认文案/平台/隐私/AI 声明；发布命令只跑一次；封面已生成 |

## 回退规则

- 用户改 idea / 平台 / 画幅 → 回到阶段 0，后续全部重算（不补丁）。
- 用户改视觉方向 → 回到阶段 3，阶段 4–5 重排，阶段 6+ 作废。
- 用户改某个镜头 → 只改该镜并**重新计算帧预算与相邻转场**，不整片重排。
- 指代含糊的反馈（「第一个标题」「太快了」）→ **先确认对象再动手**；改错立即整段 revert 重来，不在错误版本上打补丁。

## 反模式（出现即停下）

1. 分镜没确认就开始截图 / 写渲染代码。
2. 用「先做出来看看」代替 styleframe。
3. 凭卡名和理解新写一个动效，而不读参考实现（= 放弃全部调校积累，质感差一档）。
4. 把审美自检留到最后一天（应逐镜进行）。
5. 制作者自己写终检报告。
6. 发布命令重跑。
